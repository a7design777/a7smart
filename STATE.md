## Відкриті питання

1. **Сценарії не запускалися на живих пристроях.** Код перевірено наскрізь
   (створення, збереження, видалення, коректні `value_type`), але фактичне
   виконання не тестувалося навмисно — це реальне житло.
2. **Термостати Remihome.** Запис `setpoint` реалізований, але всі три прилади
   були offline під час розробки. Перевірити, коли будуть у мережі.
3. **«White big switch» (`80174007c4dd572638b9`)** — у каталозі Tuya є, статус
   не віддає. Ізольований у коді, дашборд від нього не страждає, але даних
   по ньому немає. Найпростіше — перепривʼязати в Smart Life.
4. **Розподіл пристроїв по квартирах неповний** — частина лишалася без
   прив'язки. Перевірити в розділі «Квартири».
5. **Термін IoT Core** спливе — дата невідома. Коли `/api/health` покаже
   `tuyaAuthProblem: true`, продовжити в Cloud → My Services.

## Порядок оновлення прода

```bash
npm run db:migrate     # локально, якщо були нові міграції
```

Дочекатися зеленої збірки в Actions, потім на сервері:

```bash
cd /root/a7smart && docker compose -f docker-compose.prod.yml pull && docker compose -f docker-compose.prod.yml up -d --force-recreate
```

```bash
curl -s https://smart.zvyazok.com/api/health | grep -o '"version":"[^"]*"'
```

**Звірити `version` з останнім комітом до будь-якої іншої дії.**
Розбіжність означає, що збірка ще не завершилась, і поведінку дивитися рано.
